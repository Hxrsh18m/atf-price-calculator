# Arihant ATF — Purchase Price Calculator (hosted)

Password-protected static web app. Price data is AES-256-GCM encrypted
(`data.enc`) and only decrypts in the browser after the correct password.
Open the GitHub Pages URL, enter the password, and use the calculator.
Update prices with the in-app **Upload CONN.xlsx / elbow.xlsx** buttons
(parsed locally in your browser — nothing is uploaded to any server).
